## ⚡ About Me / Về tôi

**EN:** Hi! I'm **Thạch (ThachRC)** — a Vietnamese game modder and web enthusiast. I build and localize modpacks so Vietnamese gamers can enjoy the games they love.

**VI:** Chào bạn! Mình là **Thạch (ThachRC)** — một modder game người Việt, đam mê tạo và Việt hóa modpack để cộng đồng game thủ Việt có trải nghiệm tốt hơn.

- ⛏️ Creator của modpack **ThachCraft** (Minecraft) — 46 mod, 8 gói tài nguyên, 1 shader
- 🌾 Bộ mods **Stardew Valley Expanded** Việt hóa — 47 mod, 10 gói nội dung, 1 mod AI
- 💻 Đang học phát triển web (HTML, CSS, JS) & Discord Bot
- 🎯 Mục tiêu: xây dựng cộng đồng game thủ thân thiện
